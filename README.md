# Responsive Mini Shop Layout.

This project is a **Responsive Mini Shop Layout** built using **HTML** and **CSS**.  
It demonstrates how to combine **CSS Grid**, **Flexbox**, and **Media Queries** to build a responsive e-commerce-style product page that adapts smoothly to different screen sizes and devices.

## Project Objectives.

The main goal of this project was to **practice responsive design concepts** by using:

- **CSS Grid** for the main product layout
- **Flexbox** for navigation and footer alignment
- **Responsive images and text styling**
- **Media Queries** for small, medium, large (XL), and extra-large (2XL) screen sizes
- Hover and focus effects for interactive elements.
